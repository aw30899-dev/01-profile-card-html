# Personal Portfolio Page

This beginner-friendly page uses only HTML and CSS.

## Files

- `index.html` contains the content and page structure.
- `style.css` contains the colors, layout, and responsive styles.
- `img/me.png` is the profile photo used on the page.

## How the page works

The navigation links use section IDs. For example, `href="#skills"` jumps to the element with `id="skills"`. This works without JavaScript.

The `<header>` contains the home section and introduction. The `<main>` contains favorite websites, the bio, and skills. Each section has a unique `id` so the navigation can find it.

To personalize the page, replace `Your Name`, update the paragraphs and website links in `index.html`, and edit the color variables at the top of `style.css`.

Open `index.html` in a browser, or use the Live Server extension in VS Code to preview it while you edit.
